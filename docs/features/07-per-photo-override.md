# 07. 장별 설정 오버라이드

## 목적

묶음 전체의 기본 촬영 정보를 유지하면서 디지털 카메라·폰·필름 사진이 섞인 작업에서 다른 정보만 사진별로 바꾼다. 불확실한 정보의 생략과 표시 여부도 장 단위로 제어한다.

## 현재 동작

### 데이터 병합

- 전역값은 `gInfo`(카메라·렌즈·필름·날짜·설정·메모)와 `gShow`(각 항목 표시 여부)에 보관한다.
- 사진은 자동 촬영 정보 `shot.exif`와 사용자가 지정한 부분 집합 `shot.own`을 가질 수 있다.
- 부분 EXIF와 스캐너로 추정되는 정보는 `shot.detectedExif`와 `shot.exifReview`(`partial`/`scanner`)에 따로 보관한다. 채택 전에는 렌더 값에 참여하지 않으며, 명시적 채택 후 `shot.exif`로 옮긴다. 채택은 `shot.own`을 건드리지 않는다.
- 값은 `shot.own → shot.exif → 전역` 순으로 결정한다.
  - `shot.own`에 속성이 없으면 EXIF, EXIF도 비어 있으면 전역을 상속한다.
  - 문자열은 빈 문자열까지 명시적인 장별 값이다.
  - `null`은 EXIF를 건너뛰고 전역값을 쓰겠다는 상태다.
- 표시 여부는 `shot.own.show`에 해당 속성이 있으면 그 값을, 없으면 전역 표시 여부를 쓴다.
- `withShot()` 한곳에서 여섯 값과 표시 여부를 병합하므로 미리보기와 한 장·전체 내보내기가 같은 결과를 사용한다.

### 편집 범위

- 기본 범위는 **전체 기본값**이다. 이 모드에서 바꾼 값은 장별 지정이 없는 사진과 전역 사용 상태의 사진에 반영된다.
- **현재 장**을 고르면 보고 있는 사진만 수정한다.
- 필름 스트립 체크박스로 사진을 고르면 범위가 **선택 N장**으로 바뀌고, 이후 입력과 눈 버튼 변경을 선택 사진 모두에 기록한다.
- `전체 선택` 버튼은 모든 사진 선택과 선택 해제를 전환한다.
- 선택 사진들의 값이 다르면 입력란을 비우고 `여러 값 · 입력하면 N장에 적용`을 표시한다. 표시 여부가 섞여 있으면 눈 버튼을 `mixed` 상태로 알린다.
- 범위를 전환하는 것만으로 현재 유효값을 `shot.own`에 복사하지 않는다. 실제로 건드린 필드만 오버라이드한다.
- 범위 안내는 현재 사진·선택 장수·적용 대상을 한 문장으로 보여 준다. 스타일·방향별 배치는 이 범위를 따르지 않는 공통값이며 별도 안내로 구분한다.

### 복귀와 상태 표시

- 카메라·렌즈·날짜·설정의 **EXIF** 버튼은 선택 대상 중 EXIF가 있는 사진에서 사용자 값을 지워 EXIF 원본을 다시 사용한다.
- 각 항목의 **전역** 버튼은 선택 대상의 값과 표시 여부를 전역으로 되돌린다. EXIF가 있는 값은 `null`로 표시해 전역 사용 의도를 보존한다.
- 필름 스트립에서 `E`는 EXIF 정보, `●`는 사용자 장별 상태가 있음을 뜻한다. 사용자 상태가 있으면 `●`를 우선 표시한다.
- 장비 프리셋도 현재 편집 범위의 해당 입력 필드에 적용된다.
- 채택 대기 EXIF가 있으면 현재 사진 또는 선택 사진의 감지 정보와 채택 버튼을 표시한다. 이 버튼은 현재 촬영 정보 입력 범위가 전체 기본값이어도 해당 사진들에만 적용한다. 수동값을 지우려면 채택 후 기존 필드별 **EXIF** 버튼을 사용한다.
- 조리개·셔터·ISO·초점거리 표시와 날짜 출력 형식은 묶음 전역이다. 장별 원본 문자열을 보존한 채 공유 렌더 경로에서 표시만 바꾼다.

### 저장과 호환

- 배치 선택과 현재 편집 범위는 세션 UI 상태이며 프로젝트에 저장하지 않는다.
- 프로젝트 v2는 여섯 장별 값, `null`, 여섯 표시 여부를 보존한다. v1 프로젝트의 기존 카메라·렌즈·날짜·설정 장별 값도 읽는다.
- 프로젝트 v2에 채택 대기 EXIF와 판별 이유를 선택 필드로 보관한다. 새 필드가 없는 프로젝트는 기존 EXIF와 수동 문자열을 그대로 읽으며, 이미 채택한 부분 EXIF를 재연결 시 다시 대기로 바꾸지 않는다.
- 사진 원본을 다시 연결하면 EXIF와 `shot.own`을 복원하고 프로젝트 순서로 정렬한다.

## 설계 결정

- 기존 `shot.own`을 확장해 별도 오버라이드 클래스나 상태 저장소를 만들지 않는다.
- EXIF와 전역 사용을 구분해야 하므로 `null`을 명시적인 전역 사용 표식으로 쓴다. JSON에서 손실 없이 보존되고 빈 문자열과도 구별된다.
- 배치 대상은 사진 객체를 담은 `Set`으로 관리한다. 정렬 후에도 같은 사진을 가리키며 프로젝트에 불필요한 UI 선택 상태를 넣지 않는다.
- 프레임 스타일·톤·레이아웃·글꼴·로고·서명은 묶음 전역으로 유지한다.

## 알려진 한계

- 장별 값 변경에는 별도 실행 취소가 없다.
- 선택 사진은 촬영 정보·표시 여부의 일괄 편집과 선택 내보내기에 사용한다. 선택 사진만 삭제하는 기능은 없다.
- 배치 선택은 프로젝트를 다시 열면 복원되지 않는다.

## 수용 기준

- [x] 특정 사진만 렌즈 표시를 켜고 전역은 끈 상태를 만들 수 있다
- [x] 전역 값 변경이 장별 지정된 항목을 건드리지 않는다
- [x] 항목 단위로 EXIF 또는 전역 기본값으로 돌아갈 수 있다
- [x] 빈 문자열과 전역 상속 상태가 구분된다
- [x] 장별 상태와 EXIF 사진이 필름 스트립에서 구분된다
- [x] 여러 선택 사진에 값과 표시 여부를 함께 적용할 수 있다
- [x] 현재 사진·선택 장수·촬영 정보 적용 범위와 스타일·방향 공통 배치를 구분해 표시한다
- [x] 미리보기와 내보내기 결과에 같은 장별 병합이 반영된다
- [x] 프로젝트 저장·복원 후 장별 값과 표시 여부가 유지된다
- [x] 부분 EXIF가 보이고 사용자 채택 전에는 장별 렌더 값에 영향을 주지 않는다
- [x] 부분 EXIF 채택 후에도 수동값·빈 문자열·전역 사용 상태를 유지한다
