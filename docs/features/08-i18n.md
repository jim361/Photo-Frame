# 08. 다국어·접근성 기반 [부분 구현]

## 목적

해외 사용자가 프로젝트의 용도와 프라이버시 원칙을 이해하고, 키보드·스크린리더 사용자가 핵심 흐름과 상태를 파악할 수 있는 기반을 만든다. 런타임 한국어/영어 전환은 별도 단계로 둔다.

## 현재 동작

### 영문 안내 기반

- README 첫 화면에 필름 스트립·인스탁스·하단 여백 결과 예시와 **English summary**를 제공한다.
- 영문 요약은 용도, 로컬 처리·외부 전송 없음, 묶음 작업, 장별 오버라이드, 레이아웃·글꼴·프로젝트 이동성을 설명하고 배포 페이지로 연결한다.
- 영문 요약에서 **현재 인터페이스는 한국어**임을 명시한다. README 영문은 런타임 UI 번역을 의미하지 않는다.

### 접근성 기반

- 첫 사진 드롭존은 버튼으로 노출되며 `Enter`·`Space`로 파일 선택기를 열 수 있다.
- 미리보기 캔버스는 이미지 역할과 대체 라벨을 갖고, 배율 표시는 키보드로 작동하는 버튼이다.
- 사진 스트립은 목록과 목록 항목으로 노출된다. 각 사진은 이름·순번을 라벨로, 현재 여부를 `aria-current`로 알리며 `Enter`·`Space`로 현재 사진을 고를 수 있다. `Shift+←/→`로 포커스한 사진 순서를 바꾸며, 배치 선택 체크박스와 삭제 버튼에도 사진명을 포함한 라벨이 있다.
- 스타일·정보 범위·레이아웃 방향·표시 버튼은 `aria-pressed`로 선택 또는 혼합 상태를 알린다.
- 눈 아이콘과 삭제처럼 아이콘 중심인 버튼에 명시적 라벨을 제공하고, 보이는 폼 컨트롤은 `label` 연결 또는 `aria-label`을 갖는지 초기화 자체 검사로 확인한다.
- 정보 범위, 내보내기, 토스트는 live region으로 상태 변경을 알린다. 내보내기 진행률은 기본 `progress` 요소로 표시한다.
- 개인 설정 버튼은 팝업 여부를 `aria-expanded`로 반영하고, 팝업은 dialog 역할과 라벨을 갖는다.
- 터치 사용자는 썸네일 아래 40px 화살표 버튼으로 현재 사진 순서를 바꾸고, 좁은 화면의 설정/미리보기 버튼으로 긴 화면을 왕복한다.
- 사진 둘레 여백은 숫자 입력 또는 네이티브 슬라이더로 조절하며, 슬라이더는 키보드 방향키로도 값을 바꿀 수 있다. 요소 위치는 정밀 이동 버튼으로 조절할 수 있다.

## 런타임 다국어 현황

- `<html lang="ko">`는 고정이고 UI 문자열은 한국어로 작성돼 있다.
- 언어 전환 UI, 문자열 사전, `navigator.language` 자동 감지, localStorage 선택 저장은 **아직 구현하지 않았다.**
- 결과물 캔버스의 장비명·필름명·메모는 사용자 입력을 그대로 그리므로 향후 UI 언어 설정과 분리한다.

## 설계 결정

- 영문 README는 현재 한국어 UI를 영어로 오인하지 않도록 제한을 함께 적는다.
- 런타임 번역을 시작하면 단일 HTML·의존성 0 원칙에 맞춰 파일 내 사전 객체를 사용한다. 라벨·버튼·안내·토스트·툴팁·placeholder·CSS 빈 상태까지 같은 사전으로 옮긴다.
- 시드 프리셋과 사용자가 입력한 문자열은 번역하지 않는다.

## 알려진 한계

- 런타임 UI는 한국어 전용이다.
- 캔버스의 대체 라벨은 합성 미리보기임만 알리며 결과물의 촬영 정보·배치를 텍스트로 해설하지 않는다.
- 캔버스 위 요소 박스·프레임 크기 핸들은 포인터 조작이며, 키보드에서는 설정의 정밀 이동 버튼·슬라이더·숫자 입력을 사용한다.
