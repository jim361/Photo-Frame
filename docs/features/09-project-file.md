# 09. 프로젝트 저장·복원

## 목적

여러 사진의 순서와 장별 촬영 정보 수정을 끝내기 전에 브라우저를 닫아도 작업을 이어갈 수 있게 한다. 사진 데이터를 localStorage나 프로젝트 파일에 복제하지 않고, 사용자가 보관한 원본과 다시 연결하는 로컬 전용 흐름이다.

## 현재 동작

- 우측 **프로젝트** 영역에서 `프로젝트 저장` / `프로젝트 열기`를 제공한다.
- 저장 파일은 `.photoframe.json`, 현재 형식은 `kind: photoframe-project`, `version: 2`다. 열기는 기존 v1과 현재 v2를 지원한다.
- 프로젝트에는 다음 정보를 넣는다.
  - 스트립 사진 순서와 현재 사진 인덱스
  - 원본 식별 정보(파일명·크기·마지막 수정 시각·MIME 형식)
  - 전역 촬영 정보 여섯 항목과 표시 여부
  - 표시·스타일·방향별 레이아웃, 현재 스타일과 내보내기 설정
  - 사진별 EXIF(카메라·렌즈·날짜·설정)
  - 사진별 사용자 값(카메라·렌즈·필름·날짜·설정·메모), EXIF 대신 전역을 쓰는 `null` 상태와 각 항목 표시 여부
  - 현재 적용 중인 이미지 로고 1개(400px 이하로 보관된 팔레트 dataURL)
  - 현재 사용하는 파일 글꼴 최대 2개(dataURL). 같은 파일을 영문·한글 양쪽에 쓰면 한 번만 포함
- **사진 원본 바이트는 포함하지 않는다.** 프로젝트를 열면 설정과 로컬 리소스를 먼저 복원하고 원본 선택을 안내한다.
- 배치 선택과 촬영 정보 편집 범위는 세션 UI 상태라 저장하지 않는다. 프로젝트를 열면 전체 기본값 범위와 빈 배치 선택으로 시작한다.
- 원본을 다시 불러오면 파일명·크기·마지막 수정 시각으로 우선 연결하고, 일치하지 않으면 같은 파일명을 폴백으로 쓴다. 연결된 사진은 프로젝트 순서로 자동 정렬된다.
- 일부 사진만 선택하면 `연결된 장수/전체 장수`를 표시하고 나머지를 추가로 불러올 수 있다.

### 글꼴과 로고 복원

- 기본 글꼴은 설정 ID만 저장한다.
- 파일 글꼴은 프로젝트의 dataURL을 검증한 뒤 `FontFace`로 등록한다. 폰트당 24MB, 합계 40MB, 프로젝트 전체 64MB 제한을 적용한다.
- PC 설치 글꼴은 파일을 복제하지 않고 PostScript 이름과 family만 저장한다. 다른 PC에서 사용할 수 없으면 기본 글꼴로 임시 표시하며 사용자가 다시 권한을 허용해야 한다.
- 프로젝트 로고는 기존 개인 팔레트를 지우지 않고 병합한다. 같은 이름의 다른 이미지가 있으면 `(프로젝트)` 이름으로 별도 저장한다.

### 열기와 저장 안전성

- 프로젝트를 여는 시점에 사진이 있으면 현재 사진을 비울지 확인한다.
- JSON 크기·종류·지원 버전·사진 manifest·글꼴 형식을 먼저 검증하고, 잘못된 파일이면 현재 작업을 지우지 않는다.
- v1의 네 장별 값은 그대로 가져오고 v2의 여섯 값·`null`·중첩 표시 여부는 허용된 키와 자료형만 정제해 복원한다. `false`, 빈 문자열, `null`도 상태로 보존한다.
- 파일 제목이 있으면 `제목.photoframe.json`, 없으면 `PhotoFrame-YYYY-MM-DD.photoframe.json`으로 저장한다. 저장 폴더가 연결돼 있으면 그 폴더를 사용하고, 아니면 브라우저 다운로드로 저장한다.

## 설계 결정

- **사진 비포함 manifest**: 수십 장의 원본을 JSON/dataURL로 복제하지 않고 작업 상태만 보관한다.
- **개인 팔레트와 프로젝트 분리**: 장비·레이아웃 프리셋 전체는 개인 설정으로 남기고, 결과 재현에 필요한 현재 설정·활성 로고·사용 글꼴만 포함한다.
- **버전 2 + v1 읽기 호환**: 장별 필름·메모·표시 여부와 전역 사용 상태가 추가되어 새 저장은 v2로 구분하되 기존 프로젝트는 계속 연다.
- **활성 리소스만 포함**: 글꼴·로고 팔레트 전체가 아니라 현재 결과에 필요한 로컬 리소스만 넣는다.

## 알려진 한계

- 원본 파일명이 바뀌면 정확히 자동 연결할 수 없다. 같은 이름 폴백은 다른 사진을 잘못 고를 가능성이 있다.
- 프로젝트 자체에는 사진이 없으므로 원본 파일을 함께 보관해야 한다.
- 배치 선택과 현재 편집 범위는 복원하지 않는다.
- PC 글꼴 파일은 권한상 프로젝트에 복제할 수 없다.

## 수용 기준

- [x] 사진 원본이 프로젝트 JSON에 포함되지 않는다
- [x] 사진 순서·현재 설정·전역 촬영 정보가 저장된다
- [x] 여섯 장별 값·표시 여부·EXIF·전역 사용 상태가 저장된다
- [x] v1 프로젝트를 열고 v2 프로젝트를 저장할 수 있다
- [x] 원본을 순서와 무관하게 선택해도 저장된 순서로 복원된다
- [x] 일부 원본만 선택한 뒤 나머지를 추가 연결할 수 있다
- [x] 잘못된 JSON을 열어도 현재 작업을 지우거나 초기화를 중단하지 않는다
- [x] 기존 개인 로고 팔레트를 프로젝트가 덮어쓰지 않는다
- [x] 사용 중인 파일 글꼴은 프로젝트에서 복원되고 사진 원본은 여전히 포함되지 않는다
