# 04. 촬영 정보 + 표시 설정

## 목적

카메라·렌즈·필름·날짜·설정·메모를 묶음의 기본값으로 입력하고, 디지털·폰·필름 사진이 섞였을 때 필요한 사진만 다르게 표시한다. 기억이 불확실한 항목은 값을 지우거나 눈 아이콘으로 숨길 수 있다.

## 현재 동작

### 입력과 적용 범위

- **입력 필드**: 카메라 / 렌즈 / 필름·기타 / 날짜 / 설정 / 메모. 설정은 조리개·셔터·ISO·초점거리 문자열이며, 메모는 줄바꿈할 수 있고 렌더에서는 빈 줄을 제외한 최대 4줄을 쓴다.
- 촬영 정보 상단에서 적용 범위를 고른다.
  - **전체 기본값**: 여섯 입력값과 여섯 표시 여부를 묶음의 전역 기본값으로 편집한다. 장별 값이 있는 사진은 유지된다.
  - **현재 장**: 보고 있는 사진에만 입력값과 표시 여부를 기록한다.
  - **선택 N장**: 필름 스트립 체크박스로 고른 사진들에 같은 변경을 적용한다. 값이 서로 다르면 입력란에 `여러 값` 안내가 나오고, 표시 여부가 다르면 눈 버튼의 `aria-pressed`가 `mixed`가 된다.
- 적용 범위를 바꾸는 것만으로 장별 값을 복사하지 않는다. 실제로 수정한 항목만 장별 상태가 되어 이후 전역 변경의 영향을 받지 않는다.
- 장비 프리셋은 입력 이벤트를 그대로 사용하므로 현재 적용 범위에 맞춰 전역·현재 장·선택 사진에 적용된다.
- 범위 안내에는 현재 사진 번호·이름, 선택 장수, 실제 적용 대상이 함께 표시된다. 바로 아래의 배치 안내는 촬영 정보와 달리 **현재 프레임 스타일·사진 방향 공통값**임을 별도로 밝힌다.

### 장별 값과 EXIF

- JPEG를 불러오면 `readExif()`가 파일 앞 256KB의 APP1/TIFF에서 Make, Model, LensModel, DateTimeOriginal, 조리개, 셔터, ISO, 초점거리를 의존성 없이 읽는다.
- 렌즈 또는 노출 설정값이 있고 알려진 스캐너 장비·소프트웨어명에 해당하지 않으면 `shot.exif`로 자동 적용한다. 카메라·렌즈·날짜·설정 중 비어 있지 않은 필드만 보관한다.
- **카메라·날짜만 있는 부분 EXIF도 버리지 않는다.** `shot.detectedExif`에 보관해 현재 사진 또는 선택 사진의 이름과 감지 값을 촬영 정보 위에 표시한다. **감지한 EXIF N장 채택**으로 해당 사진에 명시적으로 적용하며, 채택 후 입력 범위를 현재 장·선택 N장으로 전환해 촬영 정보 입력란에도 실제 적용값을 즉시 표시한다. 기존 수동 입력과 전역 사용(`null`) 의도는 유지하고 전체 기본값은 변경하지 않는다. 선택 사진의 값이 다르면 기존 `여러 값` 안내를 표시한다.
- EPSON, Coolscan, VueScan, SilverFast 등 스캐너로 추정되는 장비·소프트웨어는 렌즈·노출값이 있어도 자동 적용하지 않고 확인 안내를 표시한다. 명시적 채택은 가능하며, 채택 후에는 기존 항목별 EXIF 복귀 버튼으로 수동값을 원본으로 되돌릴 수 있다.
- 렌더 값의 우선순위는 다음과 같다.
  1. 사용자가 지정한 장별 값(빈 문자열 포함)
  2. 해당 사진의 비어 있지 않은 EXIF 값
  3. 전역 기본값
- 장별 값에 `null`을 보관한 필드는 EXIF가 있어도 전역 기본값을 사용한다. 표시 여부는 장별 지정이 있으면 그것을, 없으면 전역 표시 여부를 따른다.
- 사진 범위에서 **EXIF** 버튼을 누르면 선택 대상 중 해당 필드의 EXIF가 있는 사진을 원본 값으로 되돌린다.
- **전역** 버튼은 선택 대상의 해당 값과 표시 여부를 전역으로 되돌린다. EXIF가 있는 필드는 `null` 상태로 보관해 EXIF 대신 전역값을 계속 사용한다.
- 필름 스트립의 `E`/`●` 표시는 EXIF와 사용자 장별 상태를 구분한다. 자세한 모델과 배치 선택은 [07. 장별 설정 오버라이드](07-per-photo-override.md)를 따른다.

### 표시와 렌더링

- 각 필드의 눈 버튼으로 값은 유지한 채 결과물 표시를 켜고 끈다. 버튼은 `aria-label`과 `aria-pressed` 상태를 제공한다.
- **설정 항목 표시**에서 조리개·셔터·ISO·초점거리를 각각 켜거나 끈다. 전체 사진에 공통 적용하며 EXIF의 표준 문자열 또는 `·`로 구분한 완전한 설정 항목만 숨긴다. 자유 문장은 해석하지 않고 입력값·장별 원본 문자열을 수정하지 않는다. 기존 설정은 네 항목 모두 표시한다.
- **날짜 형식**은 입력 그대로(기본), `2026.07.19`, `2026-07-19`, `2026년 7월 19일`, `2026.07` 중 선택한다. 유효한 연·월·일 전체 날짜만 출력 시 변환하고, `2026.07`처럼 일부만 입력한 날짜나 자유 문장은 그대로 보존한다. 형식과 설정 항목 표시는 촬영 정보 범위와 관계없이 묶음 공통이다.
- 빈 값은 렌더에서 자동 생략한다. 날짜는 정보 줄과 독립된 요소이며, 메모도 별도 블록으로 배치한다.
- 날짜와 정보가 반대쪽에서 겹칠 수 있으면 정보 행을 최소 55%까지 자동 축소한다.
- 메모는 필름 스트립·여백 띠에서는 모노스페이스 저채도, 인스탁스에서는 이탤릭 산세리프로 렌더한다.
- 로고·서명은 묶음 전역이다. 사용자가 고른 이미지 로고를 `frame.logos`에 400px 이하 dataURL로 저장하거나 텍스트 서명을 쓸 수 있으며, 이미지가 있으면 이미지가 우선한다. 브랜드 로고는 번들하지 않는다.
- 로고 팔레트의 선택과 삭제는 각각 독립 버튼이다. 삭제는 확인 후 실행하며, 장비·레이아웃 프리셋과 같은 키보드·48px 조작 영역을 사용한다.

### 레이아웃과 글꼴

- 표시·레이아웃 설정은 프레임 스타일마다 분리되고, 각 스타일 안에서도 세로·가로 사진 프로파일을 따로 저장한다.
- 프로파일 항목은 한 줄/두 줄, 글자 크기, 스타일에 맞춘 `정보 영역` 크기, 인스탁스·매트 계열의 사진 둘레 여백, 가로 인스탁스 글씨 방향, 로고 크기와 요소별 드래그 오프셋이다.
- 현재 스타일·방향에 적용되지 않는 입력은 숨긴다. 인스탁스에서는 한/두 줄을 숨기고, 사진 둘레 여백은 인스탁스·매트 계열에, 가로 글씨 방향은 가로 인스탁스에 보여 준다. 균등 매트·키라인은 네 변이 같으므로 별도 정보 띠 크기를 숨긴다.
- **사진 둘레 여백 %**는 인스탁스·매트·갤러리·키라인에서 네이티브 슬라이더와 숫자 입력을 함께 제공한다. 기본 여백 대비 0~300%, 1% 단위로 같은 `borderScale` 값을 조절하며 두 입력은 서로 동기화된다. 슬라이더를 한 번 드래그하는 동안의 변경은 한 단계로 배치 되돌리기에 기록한다. 기존 스타일·방향별 프로파일을 사용하므로 설정·프로젝트·관련 프리셋 저장 형식은 유지한다.
- 글꼴·출력 비율·내보내기 설정은 묶음 전역이다. 영문·한글 글꼴을 따로 고르며 시스템 글꼴, 사용자가 허용한 PC 글꼴, 직접 선택한 폰트 파일만 사용한다. 외부 글꼴 요청은 없다.
- 개인 설정의 패널 폭·UI 배율·화면 테마(화이트/블랙)는 화면에만 영향을 주고 결과물에는 반영되지 않는다. 테마는 `frame.ui.theme`에 다른 화면 설정을 보존하며 저장하고, 프로젝트 파일에는 포함하지 않는다.
- 개인 설정은 열 때 첫 입력에 초점을 옮기고 Tab을 내부에서 순환한다. 닫기 버튼 또는 Escape로 닫으면 톱니바퀴 버튼으로 돌아온다. 입력 라벨의 불필요한 높이는 줄이되 UI를 90%로 줄여도 버튼·체크 등 주요 조작 영역은 48px 이상을 유지한다.

### 저장

- 전역 촬영 정보와 표시 여부, `metadataShow` 개별 설정 표시, `dateFormat` 날짜 형식은 localStorage `frame.settings`에 자동 저장한다. 새 항목이 없는 구버전은 모든 설정 항목 표시·날짜 입력 그대로를 사용한다.
- 장별 EXIF·채택 대기 EXIF·사용자 값·표시 여부는 사진 객체에 유지하며, 프로젝트 파일에 저장하면 원본 재연결 후 복원된다. 이미 채택한 EXIF가 다시 채택 대기로 돌아가지 않는다.
- 사진이 있는 동안 설정을 바꾸면 프로젝트 상태를 `저장 필요`로 표시하고 이탈 시 브라우저 경고를 요청한다.
- 첫 실행 값은 비어 있고 예시는 placeholder로만 표시한다.

## 설계 결정

- **전역 기본값과 장별 상태를 분리**한다. 입력 DOM은 현재 범위를 보여주는 뷰일 뿐이며 전역 저장소로 사용하지 않는다.
- 카메라·렌즈·필름은 **자유 텍스트 + datalist**를 유지한다. 장비 종류를 제한하지 않고 반복 입력만 프리셋으로 줄인다.
- 스타일·레이아웃·글꼴·로고까지 장별화하지 않는다. 한 묶음의 시각 스타일을 통일하는 것이 도구의 범위다.

## 알려진 한계

- EXIF는 JPEG APP1/TIFF의 필요한 일부 태그만 읽으며 HEIC·RAW 메타데이터는 지원하지 않는다.
- 스캐너 판별은 알려진 장비·소프트웨어 이름에 근거한 보수적 검사이며 모든 스캐너를 식별하지는 못한다. 부분 EXIF는 항상 사용자가 채택한다.
- 설정 개별 표시는 `F1.8 · 1/250s · ISO 400 · 35mm` 같은 형식을 대상으로 한다. 별도 구분자나 자유 문장을 자동 분해하지 않는다.
- 장별 촬영 정보 변경에는 별도 실행 취소 기록이 없다.

## 수용 기준

- [x] 빈 항목이 결과물에서 자동 생략된다
- [x] 입력 즉시 미리보기와 내보내기에 같은 값이 반영된다
- [x] 전역값을 바꿔도 장별 지정 항목은 유지된다
- [x] 특정 사진만 값을 바꾸거나 표시 여부를 다르게 설정할 수 있다
- [x] 여러 선택 사진에 한 필드 또는 표시 변경을 함께 적용할 수 있다
- [x] 항목별로 EXIF 원본 또는 전역 기본값으로 돌아갈 수 있다
- [x] 전역 촬영 정보와 표시 설정은 새로고침 후에도 유지된다
- [x] 부분·스캐너 EXIF 채택이 기존 수동 입력을 덮어쓰지 않는다
- [x] 기존 프로젝트의 설정·날짜 문자열은 기본 표시에서 달라지지 않는다

## 검증

- `node tools/check-metadata.mjs`: 작은 JPEG APP1/TIFF를 메모리에서 만들어 전체·부분·날짜 전용·스캐너 EXIF, 채택 버튼의 현재·선택 사진 입력 동기화와 전역·수동값 보존, 설정 항목 숨김, 날짜 형식과 구버전 기본값을 검증한다.
